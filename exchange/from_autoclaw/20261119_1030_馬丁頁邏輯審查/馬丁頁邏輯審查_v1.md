# 馬丁報告頁邏輯審查（第一版）

- 審查對象：`docs/reports/martin_v4_9966.html`（頁腳標示 Template B v1 / `scripts/tsa_w/rebuild_martin_v4.py`）
- 對照基準：`exchange/from_openclaw/TradingHistory_Analyzer_v8.5_template.xlsm`（LotTiers sheet 說明 I3–I7）＋ `docs/TSA_WhitePaper.md`
- 審查人：AUTOCLAW（AC lane）｜日期：2026-11-19

## 一、判定：有錯，而且係核心「馬丁偵測」層面嘅錯

網頁用嘅分層演算法同 Excel v8.5 規格**唔一致**，導致「層數、倍數、理論 lot」三樣輸出全部偏離。

## 二、五個實質錯誤（附頁面實數）

### 錯 1：基準 lot 定義錯
- Excel v8.5（LotTiers I3）：「基準 lot＝**出現次數最多的** lot，定為 L1」
- 網頁生成器：`base = 出現≥2次嘅最小實際 lot`（註釋自稱白皮書 v3.1 §4）
- 本頁數據：lots 0.01(282筆)、0.02(345筆)、0.03(114筆)…→ **最常見＝0.02**；頁面用 0.01 做 base。
- 影響：所有層號整體錯位。

### 錯 2：倍數偵測錯（頁面顯示 ×2.0）
- Excel（I4–I5）：m0＝基準以上最常見 lot ÷ 基準（0.03÷0.02 → **1.5**），再用最大頻繁 lot 反推校準，取最接近 0.05。
- 網頁：取相鄰層 lot 比值（0.02/0.01）＝**2.0**，直接標「偵測到馬丁 ×2.0」。
- 影響：徽章倍數錯；連帶「理論 lot」全錯。

### 錯 3：歸層方法錯（線性 vs 對數）
- Excel（I6）：`L = ROUND(LN(lot÷基準)/LN(倍數)) + 1`，容差 max(0.005, 3%)，超出→未分類。
- 網頁：`層 = ROUND(lot/base)`（線性，即 lot×100）。
- 後果：同一批交易，Excel 會得約 9–10 層；頁面得出 **L1…L58**（最大 lot 0.58 → L58）。

### 錯 4：「理論 lot」出現 1.4×10¹⁵ 嘅荒謬值
- 頁面 ① 表：L38 理論 lot ＝1,374,389,534.72；L58 ＝ **1,441,151,880,758,558.75**。
- 成因：層號本來已係線性（lot÷base），公式再套 `base×2^(L−1)`，兩個唔相容嘅定義相乘。
- Excel 無此欄——屬生成器自創，建議刪或改為「該層實際 lot」。

### 錯 5：白皮書版本錯配
- Excel 說明 C5 引用《白皮書 **v3.5**》；頁面 ② 寫「白皮書 **v3.1** §4」。
- 兩版對「基準 lot」定義已改（最常見 vs 最小），引用舊版係根源之一。

## 三、三個顯示／未填問題

1. **③ 商品分析器三塊全空白**：「指標 × BUY/SELL（）」冇內容、「止賺止蝕參考（層×方向）」空、61 級入場效益曲線顯示「可避開虧損 — ／可捕捉盈利 —」。
2. **④ 商品方向總表「L5+ 筆數」全部「—」**：欄位從未計算。
3. **⑥ 散點圖說明句錯**：「對角虛線＝MFE=MAE（線上＝入場後唔使挨逆風）」——線上代表 MFE>MAE（有利幅度大於不利），**唔等於冇逆風**（MAE 仍 >0）。應改為「線上＝有利幅度大於不利幅度」。

## 四、一個待核觀察（交 data lane）

明細表最近 50 筆中，**所有輸單嘅 MAE$ 都同 |淨利| 完全相等**（例：06-19 NZDUSD −43.55／MAE 43.55；−123.53／123.53；06-18 GBPUSD −110.62／110.62…）。Excel 定義 MAE＝持倉期間最差浮動（唔係最終虧損）。
- 若真係「全部輸單都收喺最差點」，咁 MAE 統計（平均 73.0 / P90 166.5）會系統性偏高；
- 若 CSV 嘅 Max Loss 欄本身就等於最終虧損，則 ① 嘅 MAE 指標失效，需要 data lane 核 `forex-forest` CSV 該欄定義。

## 五、建議修法（按優先次序）

1. **照 Excel v8.5 LotTiers 重寫分層**：base＝最常見 lot；m0＝基準以上最常見 lot÷base（≥2 次且 ≥1%）；用最大頻繁 lot 校準；`L=ROUND(LN(lot/base)/LN(step))+1`；容差外列「未分類」。
2. 刪「理論 lot」欄（或改「該層實際 lot」）。
3. 補 ③ 三塊、④ L5+ 筆數；改 ⑥ 說明句。
4. 用 Excel 開同一份 CSV 做 golden fixture，同網頁逐項對數（層數、每層筆數、P&L、倍數）。
5. 全站 165 頁 martin_v4 重生成 + 抽 3 頁驗收。
