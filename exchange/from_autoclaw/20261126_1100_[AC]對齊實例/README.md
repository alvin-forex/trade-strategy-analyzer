[AC] 補充：對齊實例（給老闆理解的具體數字）

假設 EURUSD 每小時收市價：
08:00 收市 1.0990
09:00 收市 1.1000
10:00 收市 1.1010

我在 09:59 看到面板值上升，於是預測「下一根（10:00 那根）會升」。

【正確做法 strict】
- 決策時點：09:59（當時只知道到 09:00 為止的資訊）
- 結果：10:00 收市 1.1010 vs 09:00 收市 1.1000 → 升 → 命中
- 用的價格，是在我落決定之後才出現的

【錯誤做法 overlap（我先前那次）】
- 我把「09:00 那根」當結果：1.1000 vs 08:00 的 1.0990 → 升 → 看似命中
- 但 09:00 那根在我 09:59 落決定之前已經完成，而我用的面板值本身正是由它算出來
- 等於用答案去答問題 → 命中率虛高（我實測 84.6%，正確計法只有 42.7%）

【時間差影響的是另一件事】
券商時間與香港時間差 2–3 小時，會令我整體把「哪一根算決策時點」推前或推後一兩根。
這會令嚴格模式的分數整體偏移，但不會造出 84% 這種級數；84% 只會由「用同一根」造成。
解決：全部時間統一換算成 UTC，並寫明「以已收 bar 收盤後作決策」。
