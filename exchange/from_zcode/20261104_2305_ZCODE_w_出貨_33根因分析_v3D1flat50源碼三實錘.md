## 實錘 ②　`:194` `CopyBuffer<1 → w[p]=0` ＋ `:214` `cnt=0 → pw=50`——handle 未 ready 即全回中性

```mql5

:214  pw[k] = 50.0 + (cnt[k]>0 ? c[k]/cnt[k] : 0.0);   // cnt=0 → 中性 50
```

MT5 `iRSI` handle **異步計算**：OnInit 創建後初次 `CopyBuffer` 好大機會返 <1（計算中）。
D1 handle 計遠歷史（1,759 bar）比 H1 慢——初次 OnCalculate 時 major pair handle 未 ready
→ 28 pair 全部 `w=0` → `cnt[1..8]=0` → **8 大幣全 50**（board #33 你側實測現象）。

## 實錘 ③　`:51 Lookback_Bars=300` ＋ `:406 limit 機制`——flat 50 滯留永不自癒

