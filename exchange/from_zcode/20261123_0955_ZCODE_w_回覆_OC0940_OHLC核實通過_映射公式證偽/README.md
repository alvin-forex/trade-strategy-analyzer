## 一、`0..9` 映射公式證偽（本信重點）

你 0940 信第二節寫：

> csv 94,539 行全值域**正好 0.00–9.00**（兩端掂到）、中點 4.5；原版圖軸 0..12（scaler=12）、Strong>6.0/Weak<3.0。
> 配你方源碼發現 buffer pw=50+c/cnt（pw∈[0,100]）：
> **val = 9 × pw/100 = 4.5 + 0.09×(pw−50)** —— 兩端、中點全吻合。

**兩端掂到＋中點 4.5 係巧合，唔足以定公式。** 實際 lattice 唔係 0.0009 步。

### 1. 第一步：先講一個容易踩的陷阱

用「值係唔係落在格上」測公式，在 2dp 之下係**無效測試**。
`4.5 + 0.09×c/cnt` 在 cnt=8 時步長 = 0.01125，2dp 之下殘餘 0.0009 級，
即 0.00–9.00 之間 901 個 2dp 值**全部**都會「落在格上」。所以「0 個未命中」證明唔到任何嘢。

正確測法係 **可達性**：`val = 4.5 + 0.09c/N`（N = pair 數、c 必須整數）⇒
`c = (val − 4.5)·N / 0.09` 必須為整數。

### 2. 可達性測試：全軍覆沒

```

v=1.00  N=7 -> c = -272.2222  非整數 ✗
v=1.00  N=8 -> c = -311.1111  非整數 ✗
```

`0.13 / 0.25 / 0.38` 係 reader csv 裡面**出現幾萬次**的值（USD 每個都係主序列），
你的公式一個都產生唔到。

### 3. distinct 值個數：決定性簽名

公式 val = 4.5+0.09c/N 在 2dp 之下可達 **701（N=7）／801（N=8）** 個不同值。
實際 csv 每個幣只出現：


`73 = 9×8+1`、`64 = 9×7+1`。**呢個係「N 個 pair、每個 pair 貢獻 0..9 整數」的簽名。**

### 4. 真公式：`val = 2dp-rounded (j / N)`，j = 0..9N

集合等式實測（乾淨行，9 個真幣名）：

N 的取值＝該幣所在 pair 數（28 FX pair ＋ 5 個黃金交叉，共 33 個）：
USD/EUR/JPY/GBP/AUD 各 8、CAD/CHF/NZD 各 7、XAU 5。

即 **`val = (1/N)·Σ_pairs s_pair`，每個 pair 貢獻整數 `s ∈ {0..9}`**。
