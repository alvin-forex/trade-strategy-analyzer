## 0｜先講診斷：38900 壞喺邊（設計結論）

實測 index_38900.html：**21 個 tab、全頁 0 個 `<script>`**。tab 切換、expand 按鈕、info 面板全部係死掣——21 個 tab-panel 得 1 個 active，其餘 20 個 `display:none` 鎖死。數據其實有填（td 空殼只佔 3%），但**九成內容被鎖喺永遠開唔到嘅面板入面**，所以「可見文本 9%」。加上 tr 只有 388（健康頁 9,226），雙重夾擊成空殼觀感。另一筆帳：呢套 template 係淺色底（#f5f7fa／白卡），同 TSA 站 martin_v4 嘅深色主題完全兩個世界。

**因此兩個 template 重寫共用一條鐵律：落錶唔靠 JS 都要完全可見。** 靜態頁（index）一律縱向平鋪＋純 CSS 摺疊；動態頁（martin_v4）fetch 失敗都要有靜態預渲染底。

## 1｜全站設計基準（兩 template 共用）

### 1.1 深色主題 token（照 martin_v4_106 現行，全站統一）

| 用途 | Token | 色值 |
|---|---|---|
| 頁底 | --bg | #0a0e17 |
| 卡面 | --card | #111520（hover #1a1f2e、zebra #151b28） |
| 邊框／表頭底 | --brd ／ --th | #1e2433 ／ #111520 |
| 正文／次要文字 | --text ／ --text2 | #d0d0d0 ／ #777 |
| 標題強調（金） | --pri | #FFD700 |
| 互動強調（藍） | --acc | #64b5f6 |
| 贏／BUY | --grn | #4CAF50 |
| 輸／SELL | --red | #FF5722 |
| 警示 | --yel | #FFC107 |

**Excel 色嘅翻譯**：老闆 Excel 用 BUY 綠 #28A745、SELL 紅 #C0392B、合計藍 #0D3B66——呢啲係淺底色，直接搬入深底會沉。翻譯規則：BUY/SELL 對應站內 --grn/--red；「合計」用 --acc 藍；淨利正負永遠 綠#4CAF50／紅#FF5722。主題切換掣（☀️/🌙）保留，淺色態先還原 Excel 原色。**評級色階照現行**：S+ #FFD700、S #FFA500、A 綠、B 藍、C 黃、D 紅、E 灰。

### 1.2 共用組件規格

- **評級章**：粗體字母＋底色 12% 透明度圓角chip；S/S+ 加微光暈。一頁最多一個大章（hero 位），其餘縮細做行內章。
- **Heat 色階（P&L 熱力表用）**：雙向——虧 #FF5722→透明、贏 #4CAF50→透明，按該表 max|值| 歸一化，絕對值細嘅格褪到近卡色，唔會滿屏紅綠。文字疊深色半透明底保對比。
- **BUY/SELL 對照表**：兩欄並排時 BUY 欄永遠左、綠頂線；SELL 右、紅頂線；中間指標名灰色。呢個左右結構全站統一，唔好一時上下一時左右。
- **圖例**：凡有 heat/scatter/累計線嘅區塊，右上角細字圖例（¥ 即 USD、pips 定義），第一次出現就講，唔好靠 tooltip 收埋。

## 2｜Template A：index_* deep 頁重寫

### 2.1 資訊架構——從 21 tab 到縱向敘事

21 個 tab 本身就是 IA 過載：一個 signal 分析頁塞 21 個維度，用戶要掃兩三屏先搵到想要嘅嘢。重寫改**單頁縱向流動＋sticky 錨點目錄**（純 anchor，零 JS），次序照「結論→證據→深挖」敘事：

| # | 區塊 | 原tab | 內容重點 | 層級 |
|---|---|---|---|---|
| 1 | **Identity 結論帶** | —（新增） | Signal ID＋平台＋大評級章＋一句話結論；六宮格核心數：總P&L、勝率、PF、盈虧比、MaxDD、馬丁判定 | H1 級，全頁最搶眼 |
| 2 | **收益曲線** | 收益曲線 | Growth 累計線＋MaxDD 標註（箭嘴＋金額）；時間軸帶 zoom 說明文字 | 首屏內 |
| 3 | **質量評分** | 質量評分 | 綜合評級分佈＋Entry vs Strategy 對照 | 中 |
| 4 | **層數分析** | 層數分析＋馬丁風險＋馬丁V3 | 層級分佈、各層平均盈虧、資金需求遞增、Pipstep——馬丁訊號嘅核心證據，呢三個 tab 合併為一區三小節 | 中高（僅次曲線） |
| 5 | **貨幣對×方向** | 貨幣對＋方向分析＋貨幣穿透 | 主表＋可展開穿透行 | 中 |
| 6 | **時間行為** | 時段＋持倉＋波幅 | 24小時分佈、持倉分佈、各層波幅 | 中 |
| 7 | **參考方案** | TP/SL＋Copy推薦＋Copy模擬＋策略對比＋市場語境＋市場×策略＋V2技術 | 合併做「進階參考」區，<details> 摺疊 | 低（預設收起） |
| 8 | **原始數據** | 倉位明細＋SET參數＋歷史記錄＋外匯新聞 | <details> 摺疊；明細表橫向掃＋sticky首欄 | 最低（預設收起） |

規則：**7、8 類用純 CSS `<details>` 摺疊**（預設收起但 summary 標題＋筆數可見），1–6 平鋪直出。錨點目錄桌面左側細欄、手機頂部橫向 chip 掃。寧願長，唔好再收埋。

### 2.2 數據缺優雅降級——六種缺法六種提示（零空殼軍規）

| 缺法 | 顯示 | 唔准 |
|---|---|---|
| ① 成個 signal 零交易 | 中央卡：「此訊號暫無平倉記錄」＋兩行可能原因（追蹤期太短／已除名）＋最後數據更新時間＋返排名頁連結 | 唔准出任何空表殼、空坐標 |
| ② 區塊整體樣本不足（n<30） | 照出，區塊題加灰章「樣本少 n=xx」，數值用 text2 灰色弱化，並喺區塊尾一句「統計僅供參考」 | 唔好靜靜哂刪咗個區塊令目錄斷鏈 |
| ③ 個別指標缺（如 MFE 欄冇數據） | 格內「—」灰字；表頭 ⓘ tooltip 話「數據源缺此欄」 | 唔准出 0、NaN、undefined、空白格 |
| ④ 子集 n=0（某貨幣對零交易） | **成行唔出**；表尾灰字「另有 x 個子集零交易已略」 | 唔准出一行全「—」嘅死行 |
| ⑤ 圖表數據點 <2 | 唔出圖，改一句文字摘要（「僅 1 筆交易，無法繪製曲線：該筆 +$123」） | 唔准出空軸空圖殼 |
| ⑥ 靜態生成失敗／半生成品 | 頁頂黃橫幅：「部分數據生成不完整（生成於 xxxx-xx-xx），將於下次更新補齊」 | 唔准扮正常 |

附帶：所有「—」必須係**明知缺**先用；生成器分唔到「缺」定「零」時一律當缺處理並計入 ⑥ 橫幅。

### 2.3 佈局要點

- **Desktop**：內容 max-width 1200px 置中；錨點目錄 sticky 左欄 160px；指標六宮格 3×2；表格 min 5 行先出 zebra。
- **Mobile**：目錄變頂部橫向 chip；六宮格變 2×3；對照表變上下兩卡（BUY 綠頂線卡、SELL 紅頂線卡）；明細表橫向掃＋sticky 首欄（時間）；所有 touch target ≥40px。
- **主題**：直接出深色（跟站），唔好再另做一套淺色優先。

## 3｜Template B：martin_v4 頁照 Excel v8.5 十 sheet 重建

大原則：**web 版唔係 Excel 縮影，係 Excel 分析動線嘅翻譯**——動線照「總覽→偵測→商品→時間→明細」，每個 Excel sheet 變一個自足區塊（有題、有圖例、有降級）。現有 CSV fetch 架構保留：互動可以做（揀商品、揀層、slider 門檻），但每個互動必有預設渲染，fetch 甩線都有嘢睇。

### 3.1 區塊次序總覽（十 sheet → 八區）

| # | 區塊 | 對應 sheet | 一句定位 |
|---|---|---|---|
| 1 | 整倉總覽 hero | 整倉總覽 | 10 秒內答「呢個訊號賺唔賺、係唔係馬丁」 |
| 2 | 馬丁偵測 | LotTiers | 基準 lot 點嚟、倍數幾多、層點歸 |
| 3 | 商品分析器 | 商品分析器 | 揀一個商品做手術 |
| 4 | 商品方向總表 | 商品方向總表 | 全場商品×方向成績表 |
| 5 | 月度樞紐 | 樞紐分析 | 邊年邊月食糊邊年邊月流血 |
| 6 | MAE/MFE 散點 | ScatData | 入場質素四象限 |
| 7 | 時間維度＋明細 | g_DASH | 星期×小時節奏＋逐筆數 |
| 8 | 使用說明（摺疊） | 說明／匯入說明 | 術語＋清洗規則＋圖例 |

### 3.2 逐區塊設計

**① 整倉總覽（hero）**
- 目的：一屏結論。左：訊號名＋**馬丁判定大章**（「偵測到馬丁 ×2.0」金框，或「未偵測到馬丁」灰章）＋交易筆數、數據範圍日期。右：六宮格（總P&L／勝率／Profit Factor／盈虧比／MaxDD $／最大lot）。下一排窄帶：MAE 平均·中位·P90、MFE 平均·中位·P90（$版細字，pips 先係主——照 Excel 說明）。底：分層摘要迷你表 L1–L5＋未分類（層／實際lot／筆數／勝率／P&L／佔P&L%），L6+ 自動摺埋一行「L6–Ln 合共」。
- 關鍵指標：總P&L（全頁最大字號）、馬丁判定、PF；PF 無虧損單時顯示「無虧損」而唔係 ∞（照 Excel 說明 r17）。
- 降級：筆數=0 → 照 Template A 規則①中央卡；分層表空 → 「未有足夠數據分層」一句＋隱藏迷你表；MAE/MFE 缺 → 成條窄帶唔出，唔出六個「—」。
- 佈局：Desktop 兩欄（左身份 40%＋右六宮格 60%）＋全闊窄帶；Mobile 直排：判定章→六宮格 2×3→窄帶 2×3→迷你表橫向掃。

**② 馬丁偵測（LotTiers）**
- 目的：令判定章可追溯——數據自己講「點解判佢馬丁」。頂行四膠囊：基準 lot（最常見實際lot）／偵測倍數（每層×）／歸層比例／校準層差；下加可摺疊「判定方法」引白皮書 v3.1 §4.3 六步（校準用「出現≥2次嘅最大lot」）。主體：層級分佈表（層／實際lot／筆數）配**每層筆數橫向條bar**（同一視覺可以做直方圖）；右側「實際 lot 分佈」次要表。
- 降級：判定未有數據 → 膠囊照出但值位「未有數據」灰字＋區塊頭灰章，bar 圖唔出；歸層比例 <80% → 黃字提示「兩成交易未合倍數，判定宜保守」；未分類佔比 >0 → 表尾一行灰字「未分類 x 筆（lot 不符倍數）」。
- 佈局：Desktop 四膠囊一行＋表左 bar 右；Mobile 膠囊 2×2、表全闊、bar 變表格內嵌迷你條。

**③ 商品分析器**
- 目的：單商品手術台——呢區係 Excel 精華（502×84），web 版要靠互動消化。頂：商品揀選器（下拉，**預設總P&L最高**，照 Excel）＋層數揀選（L1–L20／未分類，影響右側兩幅 MAE vs MFE 圖）。主體三件：a) 指標×BUY/SELL 對照表（筆數/勝率/P&L/平均贈/平均蝕/盈虧比/最深回落/avg MAE·MFE $·pips/最大lot/PF/平均持倉h——用 1.2 嗰個 BUY左SELL右結構）；b) 分層×BUY/SELL 明細表（L1–L20＋未分類，列數多時直向掃）；c) 止賺止蝕參考表（層×方向：MAE P90/P95＝止蝕參考、MFE P50/75/90＝止賺參考、平均持倉h）＋**視覺化為 Tukey box 式橫條**（MFE 三分位實體條＋MAE P90/95 虛線刻度），一眼讀到「邊層邊方向應該擺幾闊」。
- 入場效益兩表（v8.4：延遲入場 MAE≥門檻／趨勢確認 MFE≥門檻，61級）：**唔好直譯 61 行表**——改做互動 slider（門檻 pips）＋即時兩粒數（可避開虧損筆數%／可捕捉盈利筆數%）＋一條 61 級效益曲線線圖（x=門檻，y=保留盈利%），slider 位置即讀數。呢個係 Excel 做唔到、web 先做到嘅升級位。
- 降級：商品只有單方向交易 → 對照表缺方向欄收窄，標「此商品無 SELL 記錄」；層樣本 n<5 → 該層行灰化＋「樣本少」；pips 欄缺（只有$） → 表頭注明「僅 $ 版（pips 缺）」，散點圖區照樣降級。
- 佈局：Desktop 兩欄——左對照表＋分層表，右兩幅 MAE vs MFE 散點＋止賺止蝕box；Mobile 揀選器釘頂（sticky），表逐張全闊推落，散點上下疊。

**④ 商品方向總表**
- 目的：全場成績表，搵「邊個商品邊個方向係印鈔機/碎鈔機」。全商品×BUY/SELL 按勝率排（照 Excel）；欄：商品/方向/筆數/勝率/P&L/avg MAE $/avg MFE $/avg MAE p/avg MFE p/max lot/L5+筆數。
- 視覺：勝率欄內嵌微型bar＋數字；P&L 正負色；L5+ 深層馬丁暴露用黃底提示；同商品 BUY/SELL 兩行做一組（組間分隔線），首欄商品名 rowspan 合併。
- 降級：零交易子集唔出行（規則同 A④）；商品多過 20 個 → 首屏 20 行＋「顯示全部」掣（純 CSS 亦可：其餘入 <details>）。
- 佈局：Desktop 全闊表 zebra＋sticky 表頭；Mobile 橫向掃＋sticky 商品首欄，勝率/P&L 兩欄凍結喺掃動區外（資訊優先最高兩欄）。

**⑤ 月度樞紐**
- 目的：時間上嘅盈虧地圖。主體：**年×月 P&L 熱力表**（年份行×1–12月欄＋全年合計欄，照 Excel 樞紐分析），用 1.2 雙向 heat 色階；滑鼠/點擊格顯示精確值。下方可摺疊：商品×方向×月 明細樞紐（呢張表闊，預設收起，展開時橫向掃）。
- 降級：不足一年 → 只有月份行照出，缺失月份格用卡底色＋「·」表示「未覆蓋」而唔係 $0（分清「冇數」同「蝕零」——呢個係 Excel 做唔好嘅位，web 要做對）；淨得一個月 → 熱力表降級做單月 bar。
- 佈局：Desktop 13欄全闊；Mobile 兩級——先出「年度摘要卡」（每年一行：全年P&L＋最佳/最差月），展開先見 12 月熱力（橫向掃），明細樞紐一律 <details>。

**⑥ MAE/MFE 散點**
- 目的：入場質素——「贏嘅單贏得靚唔靚、輸嘅單輸得冤唔冤」。兩幅並排：BUY（MAE x 軸 vs MFE y 軸）、SELL 同；點色：淨利正綠負紅；加 y=x 對角參考虛線（線上=入場即唔使挨）；軸單位 pips（照 ScatData）。右上角細讀數：r 或「線上比例 xx%」。
- 降級：pips 欄缺 → 出 $ 版但軸標明「$（pips 缺）」；點 <10 → 散點改列點表（MAE/MFE/淨利 三欄小表）；單方向無數 → 淨出另一幅＋灰字「無 SELL 記錄」。
- 佈局：Desktop 兩幅並排等大；Mobile 上下疊，兩幅共享圖例只出一次。

**⑦ 時間維度＋明細（g_DASH）**
- 目的：交易節奏＋埋手數據。三小節：a) **星期×小時 P&L heatmap（7×24）**——g_DASH 星期/小時兩組公式嘅正確翻譯，格色雙向 heat，右/底邊緣做行列合計色條；b) 每日/每月累計 P&L 走勢窄幅線圖（Growth 觀念照說明 sheet：按平倉時間累計）；c) 明細表：平倉時間/商品/方向/P&L/MAE$（照 g_DASH 首十欄，唔好照 RawData 33 欄全塞——33 欄版本入 <details>「完整欄位」）。明細預設最近 50 筆＋分頁。
- 降級：開倉時間缺（只有平倉）→ 星期/小時以平倉時間計算並喺圖例注明「按平倉時間」；heatmap 全零 → 出「交易集中於時段：—」灰卡唔出空格海；明細多過 2000 筆 → 分頁＋「跳至最舊」。
- 佈局：Desktop heatmap 全闊（格 ~28px），走勢兩幅並排，明細全闊；Mobile heatmap 橫向掃（7 行高度完整保留）或縮做 7×4 時段桶（亞洲早盤/歐盤/美盤/深夜）二選一，走勢上下疊，明細橫向掃＋凍結時間欄。

**⑧ 使用說明（摺疊）**
