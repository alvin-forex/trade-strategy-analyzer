# FIX-TD5（急）：DDGuard「幽靈 SYMBOL」根因＝TD 數據檔冇帳號隔離

老闆 23:27 報：某帳戶 DDGuard TAB 出現從未交易過的 SYMBOL。

## 一、根因（代碼實證，v1.51）

| 位置 | 事實 |
|---|---|
| L197 | `string TRADES_FILE = "TD_trades.csv";` ← **檔案名寫死，冇 AccountNumber()** |
| L182 | `string SNAP_BIN  = "td4_snap.bin";` ← 同樣寫死 |
| L178 | `string REC_FILE   = "TD_records.csv";` ← 同樣寫死 |
| `LoadTrades()` L1635-1690 | 逐行讀 CSV，**冇任何帳號欄／帳號比對**；CSV 表頭亦冇 account 欄 |
| `DD_BuildSymbols()` L1057 | 表格符號 = `t_symbol[]`（即 CSV 內容）＋ live 持倉 → **上一個帳戶的平倉記錄會留低** |
| `Calculate` MaxDD 欄 | 由 `t_calcPnl[]` 累加 peak/trough → **跨帳戶數字混算，會出現 682%、20976 這類離譜值** |

結論：**同一個 terminal 只要曾經登入過別的帳戶，該帳戶的平倉歷史就留在 `MQL4/Files/TD_trades.csv`，
新帳戶的 DDGuard 會照讀，於是列出自己從未交易過的 SYMBOL，MaxDD 兩欄亦係別人的數。**

## 二、安全影響（要分清，唔好嚇人）

- **真正觸發風險控制嘅算式只計 live floating**：`if(-floating >= base*DDG_SymMaxDDPct/100.0)`（L3520），
  `floating` 逐張 `OrderSelect` 現價計 → **唔會用被污染的 MaxDD 欄**。所以防護行為本身安全。
- 被污染嘅只係：SYMBOL 清單（多咗幽靈行）＋ `MaxDD %` / `MaxDD $` 兩欄數字。
- 另外 `DDG_Symbols=="" 時 syms=Symbol()`（只用圖表當前品種），所以幽靈 SYMBOL 亦唔會令守衛去劈錯單。

## 三、修法（v1.53，與 BINGO 板可同一批或先行）

1. **全部 TD 檔加帳號前綴**
   - `TD_trades.csv` → `TD_<acct>_trades.csv`
   - `td4_snap.bin` → `TD_<acct>_snap.bin`
   - `TD_records.csv` → `TD_<acct>_records.csv`
   - `TD_summary.csv` → `TD_<acct>_summary.csv`（下游 python／TSA 讀取器要同步改，見下）
2. **CSV 表頭加 `Account` 欄**（第二道防線）：`Ticket,Account,Symbol,...`；`LoadTrades()` 見到唔同 account 即 skip。
3. **帳號變更偵測**：`OnInit` 記錄 `g_acct`；`OnTimer` 內若 `AccountNumber() != g_acct` → 清 `t_*` 陣列 + `LoadTrades()` 重載 + `LoadRecordsBin()` + `DDG_LoadState()`。
4. **一次性遷移**：若新檔名唔存在但舊 `TD_trades.csv` 存在 → 讀入後**只保留與當前帳號相符者**（無法判斷時整份當作外來，另存 `TD_trades.csv.legacy`，唔准直接用）。
5. **下游同步**：`main/scripts/` 內任何讀 `TD_trades.csv` / `TD_summary.csv` 的腳本要支援新檔名（glob `TD_*_trades.csv`）。

## 四、老闆即刻可做（唔等新版）

出問題嗰個 terminal → `MQL4\Files\` → 將 `TD_trades.csv`、`td4_snap.bin` 改名為 `.bak`（或刪）→ 圖表上重新整理 EA（F7／右鍵 Refresh）。
幽靈 SYMBOL 即刻消失，MaxDD 兩欄歸零重建。
代價：該帳戶本地快照清零，會由 terminal History 重新 sync（所以要順手右鍵 History → All History）。

## 五、驗收

| 閘 | 內容 |
|---|---|
| 隔離 | 同一 terminal 先後登入 A、B 兩個帳戶 → B 的 DDGuard 只顯示 B 有交易的 SYMBOL |
| 檔案 | `MQL4/Files` 同時存在 `TD_A_trades.csv` 與 `TD_B_trades.csv`，互不覆蓋 |
| 回歸 | Positions tab 統計、TD_summary、TSA 讀取鏈全部照舊 |
