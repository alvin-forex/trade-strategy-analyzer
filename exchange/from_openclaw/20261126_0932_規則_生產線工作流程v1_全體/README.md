# [本機] 生產線工作流程 v1（老闆 11-26 09:31 指示）——全 AGENT 必讀必行

## 生產線總覽（一件工作由誕生到收貨）

### A. 誕生（OC）
1. 需求入（老闆指示／巡板發現／agent 回報）→ 1 小時內開卡（GitHub Issues）
2. 派工信必附 **預期結果**：交付物路徑＋達標指標（數字）＋驗收步驟

### B. 執行（ZCODE／AC／DA）
3. 開工前：查卡＋知識庫＋文檔（知識先行）→ 報缺口≤5
4. 缺口要 OC 裁 → OC 4 小時內裁（唔裁＝老闆點名 OC）
5. 裁決落地 → 執行 → 機器閘自檢（測試綠／compile 0-0／紅線 0）

### C. 審批（DA-Review，設喺 AC 部機）
6. 交付 → DA-Review 對照預期結果逐項審：PASS／FAIL（列明邊項唔達）
7. PASS → 自動併／上線；FAIL → 退原 agent 重做（12 小時內再交）

### D. 收貨（OC→老闆）
8. OC 巡板（每小時）發現 PASS 交付 → 匯報老闆簽收
9. 老闆話唔 OK → 照退，責任鏈重跑

## 各 agent 責任一句話
| 角色 | 責任 |
|---|---|
| OC | 開卡派工（附預期結果）／4小時裁決／6小時驗收轉交／巡板 |
| ZCODE | 執行＋機器閘自檢＋交付信＋完工記錄 |
| AC | 數據分析／Vercel 運維／S7 重算／監督 DA-Review |
| DA-Review | 只做審批：對照預期結果逐項核，PASS/FAIL |
| 老闆 | 需求入／方向裁決／最終簽收 |
