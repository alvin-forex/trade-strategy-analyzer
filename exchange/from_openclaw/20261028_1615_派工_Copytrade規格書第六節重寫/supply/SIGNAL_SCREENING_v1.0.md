## 0. 為什麼需要這一層

老闆原方法：選「生存時間長、勝率高、持倉時間短、馬丁層數少、盈虧比高」的 signal。

實測 12 個 signal，用寬鬆門檻（span ≥ 365d、勝率 ≥ 65%、持倉 ≤ 24h、層數 ≤ 10、PF ≥ 1.5）：
**通過 0 / 12。**

不是門檻太嚴，而是這 5 個條件之間存在結構性衝突（見第 2 節）。
方向是對的，但需要換一組度量。

## 2. 為什麼原 5 條件會 0/12

### 2.1 條件互相衝突

| 條件 | 單獨通過 | 衝突對象 |
|---|---:|---|
| 持倉 ≤ 24h | 5 | 高勝率的馬丁策略多數持倉數十至數百小時 |
| 最大層數 ≤ 10 | 6 | 真正賺錢的層數多（p11623 78 層、p12787 13 層） |
| PF ≥ 1.5 | 10 | p10581 是 1.47，差 0.03 就出局 |
| 勝率 ≥ 65% | 8 | 與「層數少」負相關（r = −0.30） |
| 生存 ≥ 365d | 8 | 高勝率 signal 多數年輕（p22828 273d、p26953 205d） |

### 2.2 「盈虧比高」會錯殺最賺錢的

| signal | 真實淨利 | 盈虧比(payoff) | 判定 |
|---|---:|---:|---|
| p26953 | **+79,438** | **0.44** | 盈虧比最低，卻是賺最多 |
| p26370 | +281 | 9.99 | 盈虧比最高，卻只賺 $281 |

p26953 用 2.0 手固定倉做 XAUUSD，勝 84.8%，平均贏 $600、輸 $2,700，靠高勝率覆蓋低盈虧比。
**用「盈虧比 ≥ 1.5」篩，它第一輪就出局——而你會失去最賺錢的 signal。**

### 2.3 「層數少」不等於安全

| signal | 最大層 | 手數倍數 | 最差單鏈 | 單鏈浮虧上界 |
|---|---:|---:|---:|---:|
| p11623 | **78** | 6× | −26 | 752 |
| p34206 | 15 | **292×** | −1,011 | 7,841 |
| p13489 | 98 | 57× | −4,820 | 6,473 |

p11623 表面 78 層很嚇人，但手數只放大 6 倍、最差一條鏈只虧 $26。
p34206 只有 15 層，手數卻放大 292 倍（0.02 → 5.84）。

**真正決定風險的是「手數倍數 × 最差鏈虧損」，不是層數。**

### 維度 5：signal 之間的重疊（組合風險）

這是完全沒被看的一層。用月度盈虧算相關性：

| pair | r | 判讀 |
|---|---:|---|
| p11623 – p12888 | **0.93** | 同一底層策略 |
| p12888 – p21609 | 0.89 | 同一底層策略 |
| p10581 – p11623 | 0.88 | 同一底層策略 |

## 4. 建議架構：從硬門檻改成「漏斗 + 評分」

### 4.1 為什麼不用硬門檻

硬門檻的問題是**一刀切**：p10581 的 PF 是 1.47，門檻 1.5，差 0.03 就全盤出局——但它在延遲、層數、一致性上都合格。

而且門檻是**事後擬合**的：你看到歷史數據後設 1.5，這個 1.5 對未來沒有預測力。

### 4.2 五層漏斗（每層只做淘汰，不做排序）

| 層 | 檢查 | 門檻 | 淘汰理由 |
|---|---|---|---|
| **L0** | 數據乾淨 | 排除非交易行、日期可解析 | 不修就全錯 |
| **L1** | 樣本足夠 | n ≥ 300 且跨度 ≥ 180d | 統計不可信 |
| **L2** | 真有 edge | PF ≥ 1.5 且前後期 PF 均 > 1 | 可能只是運氣 |
| **L3** | 風險形狀 | 層數 ≤ 10、最差單筆佔淨利 ≤ 25%、剔除最賺仍賺 | 尾部風險 |
| **L4** | Copy 適配 | D=5 留存 ≥ 70%、薄利佔比 ≤ 10%、持倉 ≤ 24h | 你跟不到 |
| **L5** | 組合可用 | HHI ≤ 5,000、與已選 signal 相關性 < 0.6 | 重疊不分散 |

實測結果：

```
L0 數據乾淨   11/12   ← p13489 出局（真實虧損）
L1 樣本足夠    4/12   ← p10581, p11623, p12787, p9966
L2 真Edge      2/12   ← p11623, p12787
L3 風險可控    0/12
```

L3 全滅的原因：p11623 有 78 層、p12787 手數倍數 58× 且最差鏈 −$1,928。

> **結論：以「n ≥ 300」為門檻，你的 12 個 sample 沒有一個能安全通過全套。**
> 這不是壞消息——它說明「能賺錢的 signal」和「適合 copy 的 signal」是兩個不同的集合。

## 5. 兩個必須寫進流程的檢查

### 5.1 「爆倉痕跡」檢查（強制）

在 L0 加一條：**掃描 comment 中的 `reset balance`**。

p26953 的證據：

```
15/03/2026 16:46:46  balance  −12,523.50  reset balance to 6600
```

固定 2.0 手 XAUUSD、84.8% 勝率、8 個月賺 $79k —— 但中途帳戶被打到剩 6,600。

**高勝率 + 固定大手數 = 最危險的組合**。因為它靠扛單換勝率，一次逆向就抹掉數月利潤。

這條檢查必須自動化，不能靠人眼。一個 signal 若曾重置帳戶，勝率再高也要降級。

### 5.2 「紙上富貴」檢查

p22828 的已實現回撤只有 **$13**（佔淨利 0.2%），看起來完美。
但它的 `Max Loss` 最差是 **−$3,253**，有 5 筆曾浮虧超過 $500。

**已實現回撤 ≠ 你要承受的風險。** copy 時你會實時承受浮虧：帳戶淨值會先跌 $3,253 才回升。

所以風險指標要看 `Max Loss`（浮虧），不能只看已實現盈虧曲線。

## 6. 這層在整體流程的位置

```
S 層（新增）         M0 ──→ M1 ──→ M2 ──→ M3 ──→ M4/M5 ──→ M6 ──→ M7
signal 篩選          規格    計錢    正規化   分層    Copy/TP-SL  匯總   顯示
    │
    └─ 輸入：12 個 CSV
       輸出：入選 signal 清單 + 每個的風險限制（層數上限、商品範圍）
```

S 層輸出必須包含**每個 signal 的風險參數**，傳給 M4/M5：

| 輸出欄位 | 用途 |
|---|---|
| signal_id | 主鍵 |
| tier (A/B/C/D) | 分流 |
| max_layers_allowed | M3/M4 的上限 |
| max_lots_cap | 風控 |
| delay_tolerance_pips | Copy 可接受延遲 |
| correlation_group | 避免組合重疊 |

**這一步的價值**：把「開幾層馬丁」從憑感覺變成有依據。p11623 有 78 層歷史，但評分卡會告訴你限制到第 10 層——因為第 11 層以後的浮虧超出單一策略的合理風險預算。
