## 2. (b) 已定案：**包含正在跳動嘅 K 棒**

### 測試設計
若只用已收 K 棒 → 面板值喺同一根 bar 內**唔會變**，只會喺 bar 交界瞬間跳一次。

### 三條硬約束（後續任何候選都必須同時過）

| 約束 | 原作實測 | 容許 |
|---|---|---|
| sd(U) / 模型 | 1.37 – 2.07 | 0.9 – 1.1 |
| 跨幣相關（8 幣平均） | **−0.108**（模型 −0.042） | 同號且 |差| < 0.10 |

| U 上限 | GBP/AUD/USD 72/72、NZD/CHF/CAD 63/63、XAU 45/45 | 必須全部命中 |

**「sd 比 1.9」嘅物理意思**：同一隻幣對 8 個夥伴嘅 9 次比較，彼此**正相關 ρ ≈ 0.37–0.47**
（由 var ratio 反算：ρ = (ratio² − 1)/(N − 1)）。
即係歐元真係「一次過」對多數幣同向，唔係逐對獨立。

**跨幣負相關（−0.108）唔係異常**：8 個幣共用同一批 28 對，任何逐對模型都會自然產生 −0.04 左右嘅負相關。
本輪更正：早前報告「模型 +0.368，同原作反號」係我腳本嘅開關幣方向旗標寫錯，已作廢。
