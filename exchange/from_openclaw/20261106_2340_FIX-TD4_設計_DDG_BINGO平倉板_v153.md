## 二、設計（BINGO 板）

### 版面
```
┌ CLOSE BOARD ────────────── armed: BUY (8s) ── [ALL] ┐
│  BUY    SELL    WIN    LOSE │   ← 第 1 排：方向／盈虧 4 格
│  ┌────┬────┬────┬────┐                              │
│  │XAU │EURGBP│GBPJPY│EURUSD│  ← 第 2-3 排：8 個 symbol 格
│  ├────┼────┼────┼────┤                              │
│  │USDJPY│AUDUSD│(空)│(空)│                          │
│  └────┴────┴────┴────┘                              │
└─────────────────────────────────────────────────────┘
```
- 4 欄 × 3 排，格 58×30px（隨 scale），gap 3px → 板高 ~112px
- 位置：`DDRESET` 之下，`tabNeedH(tab2)` 由 355 → **~490px**
- 空格（無持倉）＝深灰底、字灰、不可按（唔會誤觸）

### 每格顯示
`第一行：組名（8px）` / `第二行：n張 · ±$浮虧（7px）`
底色：浮盈綠 / 浮虧紅 / 空倉深灰；字色白。

### 點擊行為（安全第一）
1. 第 1 下 → 變 `BUY?`（黃底），8 秒內唔再按就自動復原
2. 第 2 下（8 秒內）→ **執行該組平倉**
3. 執行後：`LogEvent` 記帳 + `TG_Notify` 推「組別／已平張數／殘留張數／該批已實現盈虧」
4. 殘留 > 0 → 格變紅閃並顯示 `RESID n`

### 第 1 排三種預設（要老闆揀一個）

| 預設 | 4 格內容 | 適合 |
|---|---|---|
| **A（建議）** | `BUY` `SELL` `WIN` `LOSE` | 一鍵劈方向／劈賺蝕，最常用 |
| B | `BUY` `SELL` `SYM` `TAG` | 以品種／註解前綴為主 |
| C | `WIN` `LOSE` `>0.5%` `>1%` | 按浮虧幅度分級（風控型） |

我建議 **A**：`LOSE` 一鍵止蝕全部輸單，係呢個 TAB 最實用嘅動作；`WIN` 一鍵收成。
（B 的 `TAG` 要讀 `OrderComment` 前綴分群，做得出但屬 v2，建議唔好第一版塞。）

### `[ALL]` 紅色鈕
獨立於 12 格，放板頭右邊。同樣雙按確認，但**顏色用橙紅 + 確認間隔 12 秒**（比格仔長），因為影響最大。

## 三、技術要點（給 ZCODE）

1. 新增 `DDG_CloseFilter(int mode)`：mode 0=BUY 1=SELL 2=WIN 3=LOSE 4=SYM(id) 5=ALL
   - 重用 `DDG_CloseSymbolWithRetry` 的 body 抽成 `DDG_CloseMatch(mode,id)`，避免第三份重複 close 迴圈
   - 平倉前後 `RefreshRates()`；每輪 `Sleep(150)` 保留
2. 新增狀態：`int g_bingoPendMode; int g_bingoPendId; datetime g_bingoPendT;`（8s / ALL 12s）
3. 筆數／浮虧：掃 `OrdersTotal()` 即時算，**唔好用 `t_` 陣列**（`t_` 係平倉記錄，冇未平倉單）
4. 物件命名：`BGH`(板頭) / `BGA`(ALL) / `BGM_<0..3>`(第1排) / `BGC_<0..7>`(symbol 格) / `BGT_<n>`(格內文字)
5. `HideMainTable()` 加：`ObjectsDeleteAll(0,PFX+"BG")`（一個前綴掃清）
6. `tabNeedH` 的 tab2 分支加 `+ 116*scale`
7. 面板高度保險：`panelH = MathMin(panelH, ChartHeightPx-30)`，若被夾就自動隱藏 `TAM2` 提示行（現時無任何垂直夾，係潛在跌出圖底缺陷，順手修）

# 定稿 v2（00:34 老闆更正版面）— 按鈕跟 SYMBOL 同一行右方

## 版面（更正前一版「群組列」的錯讀）

```
┌ CLOSE BOARD ── [ARM] 58s ───────────── 1/2 [<][>] ┐
│ EURJPY   3張   -$182.40   12.6%   [BUY][SELL][WIN][LOSE][ALL] │
│ USDCHF   2張    -$64.20    8.1%   [BUY][SELL][WIN][LOSE][ALL] │
│ GBPCHF   6張    -$31.05    3.9%   [BUY][SELL][WIN][LOSE][ALL] │
│ ...（動態，最多 28 個品種）                                   │
├────────────────────────────────────────────────────┤
│ LAST: LOSE 3張 -$182.40 @00:05        [ CLOSE 全倉 ] │
└────────────────────────────────────────────────────┘
```

- **每個 SYMBOL 一行**，5 個按鈕都排喺該行右方 → 每行只管自己嗰個品種
- 排序：浮虧最差行最上（最急要處理喺頂）
- 行內先睇數字再按：張數 / 浮虧 / 佔 balance %
- 無獨立「群組列」，全域只剩底部一個 `[CLOSE 全倉]`

## 每行 5 個按鈕語意（只作用於該行 SYMBOL）

| 按鈕 | 平倉範圍 |
|---|---|
| `BUY` | 該品種 BUY 方向持倉 |
| `SELL` | 該品種 SELL 方向持倉 |
| `WIN` | 該品種浮盈持倉 |
| `LOSE` | 該品種浮虧持倉 |
| `ALL` | 該品種全部持倉（**保留掛單**） |

## 全域按鈕

| 按鈕 | 平倉範圍 |
|---|---|
| `[CLOSE 全倉]` | 全部品種所有持倉 ＋ **刪除所有 pending orders**（真正清光） |

## 尺寸與高度

- 行寬預算：面板實寬約 1208px（scale=1）→ 名稱 70 + 張數 45 + 浮虧 75 + % 50 + 5×48 按鈕 = 約 450px，**單欄夠位，無需分兩欄**
- 行高 15px；28 行 = 420px
- **高度自適應**：用 `CHART_HEIGHT_IN_PIXELS` 算可容行數，超出即分頁（`1/2` + `<` `>`），不會跌出圖底
