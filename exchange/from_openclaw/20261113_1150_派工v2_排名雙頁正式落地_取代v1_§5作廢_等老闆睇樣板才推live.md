### 2.4 PF 哨兵修正（**現有 live 頁真 bug，必須一併修**）

DB 用 `pf_raw = 999` 表示「無虧損單」。舊 `generate_ranking_ccy_v5.py` 把它當 **0** 加權：

- `43024 AUDCAD SELL`：15 手 **100% 勝率**、淨 +834p → 舊頁顯示 **PF 0.36**（實應 1.09）
- 全站 10 個組合屬「全勝零虧損」→ 舊頁 PF 0；**新規格顯示 `∞`**

規則：只用 `0 < pf_raw < 100` 的行加權；整組皆哨兵 → `pfINF=true`，前端渲染 `∞`。

### 2.5 馬汀層級統計

層級手數由 `layers_json` 加總；層級 WR/PF **只用單層列**（`lv` 恰為 `L\d+`）的真實值，冇就顯示 `—`（唔准用多層混合值假造）。目前覆蓋 661 個 `(combo, lv)`。

## 三、⚠️ 加密（**呢個係上線前唯一 blocker**）

repo `alvin-forex/trade-strategy-analyzer` 係 **public**（`visibility: public`、Pages 開啟）。舊頁用 staticrypt 加密；新架構 JSON 獨立，**任何人知道網址即可 fetch 明文 JSON，密碼等於被繞過**。

採用方案 A（老闆 09:17「按你建議做」已批）：

1. `data/*.json` 用 staticrypt 同一套 PBKDF2（1000→14000→585000 三輪）+ AES-CBC 加密成 `data/*.json.enc`。
2. 頁面解鎖後（staticrypt 已在 localStorage 存 hashedPassword）用同一 key 在瀏覽器解密，**唔需要第二次輸入密碼**。
3. **唔准**把明文 JSON 推上 Pages；`data/` 加 `.gitignore` 排除明文，只 commit `.enc`。

若 staticrypt 3.5.4 嘅 hashedPassword 取用有困難，先出「獨立密碼 + 一次輸入」的 fallback，並在回執講明，唔准靜靜雞放明文。
