## P7-1 補充｜快捷入口溢出（對應原 P7 第 3 項）

**實測**（`shot_quick_entries.jpg`）：

| 觀察 | 細節 |
|---|---|
| 按鈕數 | 4 個膠囊：`時段統計` / `MFE / MAE` / `資料庫瀏覽` / `MT5 工具` |
| 溢出 | **第 4 個「MT5 工具」被容器右緣裁切**，必須橫向捲動才看得到 |
| 捲軸 | 出現可見的水平捲軸，**淺色軌道在深色主題裡非常突兀** |
| 底註 | 現有說明文字寫「與導航 6 項零重複（設計基準 §2.4 去重懲律）」 |

**要求**：

1. **不得靠橫向捲軸**。容器寬度不足時改為自動折行（`flex-wrap: wrap`），
   或按斷點減至 2×2。橫向捲軸在手機與桌面都不接受。
2. 捲軸樣式（若任何地方仍需要）要跟深色主題一致，不得出現淺色軌道。
3. 保留原 P7-3 的「展開／收起 + localStorage 記憶 + 手機預設收起」要求，
   但**收起狀態下也不得出現橫向捲軸**——收起時應該只顯示第一行且完整不裁切。
4. 底註文字「§2.4 去重懲律」用詞請確認是否為「懲律」還是筆誤；
   若為設計文件章節編號，保持原樣並在 manifest 回覆說明。

**驗收**：1280px 與 390px 兩個寬度截圖，四個按鈕全部完整可見、無水平捲軸。

## P7-2 補充｜地圖標記重疊與裁切（對應原 P7 第 1 項）

**實測**（`shot_map_events.jpg`）：

| 問題 | 具體位置 |
|---|---|
| 重疊 | **CAD 圓圈壓在 USD 圓圈上緣**，兩個標籤互相干擾 |
| 重疊 | **AUD 與 NZD 圓圈重疊**，NZD 標籤被 AUD 圈部分遮擋 |
| 重疊 | **GBP 標籤壓在 CHF 圈上方** |
| 文字被裁切 | NZD 上方的 `HIGH` 標籤右側被切掉，顯示成 **`HIGI`** |
| 邊界溢出 | NZD 圓圈下緣貼近／超出面板底邊 |
| 版面失衡 | 地圖整體偏左上，**JPY 以右大量留白**，視覺重心偏移 |

**要求**：

1. **標籤防碰撞**：加一個簡單的標籤避讓（label collision avoidance）——
   兩個標記距離小於閾值時，其中一個的 HIGH/MED 標籤換到另一側（上／下／左／右
   取空間足夠者），或改為只在 hover 時顯示，靜態時只留圓圈。
   **不接受**文字被裁切（`HIGI` 這種情況）。
2. **邊界內縮**：所有標記與其標籤必須完整落在面板可視區內，加 padding 約束。
3. **水平重心**：整體標記群的 bbox 水平居中，或按經度分佈調整 viewBox，
   不要讓右半邊（JPY 以右）大量留白。
4. 與原 P7-1（國家數由 5 增至至少 9、環半徑 scale 1.4~1.8、抽象化熱點圈層）
   一併做——**國家數增加後重疊只會更嚴重**，所以防碰撞係前置條件，唔係可選項。

**驗收**：截圖中所有 `HIGH` / `MED` 標籤完整可讀（無裁切字元）、
無兩個標籤互相遮擋、所有標記在面板邊界內。
