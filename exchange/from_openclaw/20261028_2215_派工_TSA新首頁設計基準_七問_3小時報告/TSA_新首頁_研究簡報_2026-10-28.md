## 1. 適用範圍

TSA 新首頁（`docs/index.html` 或 `docs/home.html`）＋其延伸嘅 EA 面板一致性。現時首頁係淺色卡片風（#f5f7fa＋藍紅），要轉深色科技感。

## 2. 量化規範（可直接寫入設計稿）

| 項目 | 數值 | 出處 |
|---|---|---|
| 微互動時長 | **100–300ms**（重要動作可到 300–400ms），用平滑 velocity curve | Medium design-bootcamp；noboringdesign |
| KPI 卡數量 | 每屏 **≤5 個** 決策型指標；頂部 3–4 個大卡＋1–2 個次卡 | tabulareditor KPI best practices；epcgroup Power BI 2026 |
| KPI 擺位 | 頂部、按決策範疇分組，先建立語境 | omni.co data-viz best practices |
| 對比 | 正文 ≥4.5:1、狀態/徽章 ≥3:1（沿用 EA brief 同一標準） | W3C 慣例 |
| 動畫可及性 | 尊重 `prefers-reduced-motion`，關閉所有非必要動效 | 通用 a11y 慣例 |
| 特效克制 | 「少許」＝數字 count-up 300–500ms、hover 1px 微光邊、背景 dot/grid opacity ≤0.04；**唔用粒子/視差** | 微互動文獻共識：subtle, functional |

## 3. 版面參考（高分金融 dashboard 共性）

- 頂部：**3–4 個大 KPI**（帳戶淨值、當月增長、排名升跌、今日 HIGH 事件數）
- 中段左：走勢（外匯＋商品指數，SVG sparkline 手繪，唔引 Chart.js）
- 中段右：外匯新聞（HIGH 優先、帶倒數）
- 下段：SIGNAL 排名表（按當月增長排序；**rank order list 模式**：預設簡單排序＋可切換欄位，唔一次過畀 10+ 個 filter）
- 上載區唔好放首屏正中——老闆日常係「睇」多過「傳」，上載改成右上固定按鈕開 drawer
- 排名表 UX：預設 sort 明確可見、每欄可點排序、長 token 要 `overflow-wrap:anywhere`（任務板 c30ed0b6 教訓：445px 撐爆 388px 卡）
