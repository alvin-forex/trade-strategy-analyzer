## 三、設計方向（待設計師確認／修正）

- **風格**：深色為底（同 Muse v1.0 tokens 對齊：#0F1520 / #161E2E / #2A3650，txt #E6EDF5），accent 用 sem/info #5CA8FF ＋ sem/ok #3DDC84
- **特效**（「少許」＝克制）：
  - 數字滾動（count-up）只在 KPI 卡，300–500ms
  - 卡片 hover 微光邊（1px gradient border，唔用大陰影）
  - 背景：極淡 grid 或 dot pattern（opacity ≤0.04），**唔用粒子動畫**（食電、手機卡）

- **響應式**：手機 390px 單欄、桌面 1280px 三欄（老闆常用手機睇）
- **加密**：首頁若含排名／帳戶數據 → 同其他 admin 頁一樣 staticrypt 加密（salt 2f5a7c9e）
