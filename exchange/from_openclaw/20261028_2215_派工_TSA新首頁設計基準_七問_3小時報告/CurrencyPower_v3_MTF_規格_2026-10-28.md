# CurrencyPower v3.11 — Multi-TF 規格（老闆 2026-10-28 21:47：必須）

> 現狀：CP v3（v3.10）只計**當前圖表 TF**，單一讀數。
> 老闆要求：**必須加入 Multi-TF 概念**——對齊商業 CCY Power .ex4 嘅跨 TF 能力（見對比表第 3 節「TF 結構」分歧點）。

## 一、三層設計（缺一不可）

### L1 每 TF 獨立讀數
- TF 組：**M15 / H1 / H4 / D1**（四檔，可配置增減）
- 每個 TF 獨立計 power 0–100（沿用現行 ATR% 加權公式，只換資料源 TF）
- 資料：`CopyRates(symbol, tf, 0, N)`，每 TF 取 ≥100 bar（ATR% 需要）

### L2 加權複合分（面板主數字）
- 預設權重：**H1 40% / H4 30% / D1 20% / M15 10%**（input 可調，總和自動正規化）
- 複合分 = Σ(power_tf × w_tf) / Σw_tf
- 中性 50 不變；≥70 / ≤30 觸發 Alert（沿用 B3 去重邏輯）

### L3 對齊度 Alignment（老闆要嘅「Multi TF 概念」核心）
- 定義：四檔 TF 中，方向同複合分一致（同邊）嘅數量 → `3/4`、`4/4`
- 顯示語義：
  - **4/4 = 全對齊**（綠 badge，最強信號）
  - **3/4 = 大致對齊**（黃）
  - **≤2/4 = 分歧**（灰，唔建議入場）
- 呢個係判斷「趨勢一致性」嘅關鍵，比單一 power 值有用

```
  EUR   ▼ 41.5   M15 ▮  H1 ▮   H4 ▮▮ D1 ▮

```
- 貨幣行：複合分大字（T1 10pt bold）+ 右側四個 mini 方向格（▲▼▬，唔用 bar 圖避免 object 爆炸）
- 標題右側：ALIGN n/4 badge
- 每個 TF 格顯示：方向符號 + 可選數值（input `ShowTFValues`）
- object 預算：8 貨幣 × 4 TF = 32 個新 object，加現有 ~25 = ~57，**貼近 60 上限** → 用單一 label 拼字（如 "M15▲ H1▲ H4▼ D1▲"）可壓到 8 個 object，**建議用拼字法**

## 三、效能紅線（必須）

1. **唔准每 tick 重算 4 TF**：OnTimer 5s 一次（沿用 v3.10 節流）
2. **按 TF 收盤快取**：H1 每小時最多重算 1 次、H4 每 4 小時、D1 每日——用 `iTime(symbol, tf, 0)` 變更檢測
3. **首次載入**：四 TF 全部算一次，之後靠快取
4. 資料不足（新 symbol 歷史唔夠）→ 該 TF 顯示 `N/A`，**唔准估算**（寧可空白）

## 四、設定項（input）

| 名稱 | 預設 | 說明 |
|---|---|---|
| `MTF_TFs` | M15,H1,H4,D1 | 參與 TF（逗號分隔 enum） |
| `MTF_W_M15/H1/H4/D1` | 10/40/30/20 | 權重 |
| `MTF_AlignMin` | 3 | 低於此對齊度唔出強信號 |
| `ShowTFValues` | false | TF 格顯示數值 |
