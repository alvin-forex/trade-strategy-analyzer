## ⚠️ P1 退修一項｜null 值「沉底」只做咗一半

你信寫「null 值一律沉底」——**代碼層確實係咁寫**，但**預設檢視落唔到效果**，變成 null 排最頂：

**實測（預設載入，`state={k:'month_growth',dir:-1}`）**：

```
前 5 行當月增長：['—','—','—','—','—']
第一個非 null 值出現喺第 94 行（index 93）
93 行 null 全部排喺頂，user 一打開見到一片「—」
```

**根因**（`cmp()` 邏輯本身正確，問題喺 `render()` 呼叫方式）：

```js
view.sort((a,b)=>state.dir*cmp(a,b,state.k));
```

`cmp()` 用 `return 1 / -1` 表達「null 沉底」，但外面再乘 `state.dir`——**desc 時整個結果反轉，null 嘅 1 變 −1，即刻由沉底變置頂**。即：

- `month_growth` DESC（預設）→ null 置頂 ✗
- `month_growth` ASC → null 沉底 ✓（乘 +1，冇反轉）
- 其餘 6 欄剛好零 null，所以個 bug 只喺 `month_growth` 呢一欄曝露；若日後加欄有 null 會即刻復發

**修法（一行）**：null 判定要喺方向乘法**之外**處理，例如

```js
function cmp(a,b,k){
  const x=val(a,k), y=val(b,k);
  const an=(x==null||x===''||(typeof x==='number'&&isNaN(x))), bn=(y==null||y===''||(typeof y==='number'&&isNaN(y)));
  if(an||bn) return an&&bn?0:(an?1:-1);   // 永遠正數＝沉底
  ...
}
// 呼叫側
view.sort((a,b)=>state.dir*cmp(a,b,state.k) || cmpNull(a,b,state.k));
```

或最簡：`cmp` 唔再回 null 分支，改由呼叫側先 partition：

```js
const nonnull=view.filter(r=>val(r,state.k)!=null), nullsArr=view.filter(r=>val(r,state.k)==null);
nonnull.sort((a,b)=>state.dir*cmp(a,b,state.k));
const ordered=nonnull.concat(nullsArr);   // null 永遠喺尾
```

**驗收條件**（退修後我照同樣方法覆核）：
1. 預設載入 → 首行係最大正增長（唔係「—」），93 行 null 全部喺尾
2. `month_growth` 切 asc → 首行係最負值，null 一樣喺尾
3. 其餘 6 欄排序結果不變
4. 過濾＋排序互動不變
