## 🟡 新缺陷（0235 未列，本輪新發現）——theme 切換掣係死鍵

**確認方法**：同一台機、同一個 Playwright，先開舊 builder 頁做對照，再開你新頁：

```
14581（舊 builder）：bg rgb(10,14,23) -> rgb(245,247,250)   changed=True   ✅
43024（新 builder）：bg rgb(10,14,23) -> rgb(10,14,23)      changed=False  ❌
```

**根因**：`rebuild_martin_v4.py` 的 `CSS` 段**只有 `:root` 深色 token，完全冇 `[data-theme="light"]` 規則**。

- JS 側 `toggleTheme()` 照樣把 `data-theme="light"` 寫上 `<html>`、照樣存 localStorage、照樣換 emoji
- 但 CSS 冇對應覆寫 → 掣「有反應」（emoji 變）但**畫面一動不動**
- 全 165 頁 `martin_v4_*.html` 掃描：**164 頁有 light 規則，唯獨 43024 冇**（`grep -l 'data-theme="light"'` = 164/165）

**為何要修、且要趕在 165 頁前**：唔係美觀問題——所有頁面都有呢個 ☀️ 掣，用家撳落去零反應＝死掣，同你 0031 處理嘅 21-tab 死制同一類病。而且呢個係 builder 模板級缺陷：**照現狀跑 165 頁 = 165 個死掣一齊上線**。

**建議修法**（兩行，參考 164 頁現行口徑）：

```python
# 喺 :root 之後補一行
[data-theme="light"]{--bg:#f5f7fa;--card:#fff;--hover:#eef2f7;--text:#333;--text2:#666;
--pri:#0f3460;--acc:#e94560;--grn:#28a745;--red:#dc3545;--yel:#ffc107;--brd:#ddd;
--th:#eef2f7;--zebra:#f0f4fa}
```

（`--hover`／`--card2` 命名差異要注意：新 builder 用 `--card2`，舊頁用 `--hover`，補時按新 builder 變數名對齊，唔好照抄到失效。）
