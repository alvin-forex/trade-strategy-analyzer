## 二、結論（分清 bug vs 事實）

- **算式冇錯**：今日無成交，Hour 視圖全 0 係事實；浮動 DD 欄有真數（-$66~-$74）證明 records 環 buffer 正常。
- **但 UI 設計錯（O社認）**：表頭只計「當前頁窗口」，H 視圖開機就係今日 → 一開就全 0，同「Snap: 70 trades」自相矛盾，任何人睇都會判斷成「計錯」。呢個係 v1.51 之前就有嘅設計債，唔關數據事。
- **HISTORY EMPTY 係真問題**：terminal History 分頁 0 張 → EA 由 10-21 之後無法 sync 新平倉（只靠舊快照）。呢個要人手處理，代碼無法代改 terminal 歷史篩選。

## 三、v1.52 修法（請 ZCODE 出 patch）

1. **表頭改雙行**：
   - `VIEW: Hour (Latest) | 0 trades | P&L $0.00 | WR —`（當前窗口，0 張時 WR 顯示 `—` 而唔係 `0.0%`）
   - `ALL: 70 trades | P&L $+46.60 | WR 62.9% | B30/S40 | 最後成交 2026-10-21 10:44`
   → 全期數據永遠可見，唔會再出現「Snap 70 但 P&L 0.00」嘅自相矛盾。
2. **預設視圖 H → D**（`input View` 預設 1）。Hour 視圖留給日內盯盤用，唔做開機默認。
3. **空窗口明示**：當前窗口 0 張成交時，表格上方一行 `(no closed trades in this window — last close 2026-10-21 10:44)`，取代格內全 0 的靜默。
4. **HISTORY EMPTY 文案加指令**：`!! TERMINAL HISTORY EMPTY (0 orders) — right-click History → All History; 面板暫用本地快照 70 筆`，並同時顯示快照最後平倉時間，令「快照 vs terminal」兩個時間戳一眼可分辨。
5. **負零修正**：Balance/Gain$ 顯示 `-0.00` → `MathAbs(x)<0.005 ? 0.0 : x`（6DB4 Month 2026.08 就係 `-0.00`）。
6. **不動數據層**：`OrdersHistoryTotal()==0` 時 `SyncTradesFromHistory()` 保持現有 early-return（唔准 wipe CSV 快照）。

## 四、驗收（雙閘）

- 閘 2 視覺：截圖要見到雙行表頭 + 空窗口提示行 + 紅字含「本地快照」字樣。
