## 一、`scripts/rename_inputs.py`（Python 3，零依賴）

輸入：一個 `.mq4/.mq5` 檔 + 一份 JSON 對照表
輸出：改好的檔案 + 改動報告

功能：
1. 讀對照表 `{"OldName": {"new":"InpNewName","comment":"...","group":"Display"}}`
2. 全部替換，用 **word boundary 正則** `\bOldName\b`，避免誤中 `OldNameX`
3. 統計每個名的「宣告 1 次 + 引用 N 次」，逐個報告，**引用數與預期不符即報警**
4. 按 `group` 重寫 input 區塊（保留原預設值），套用 group 次序常數
5. 刪除全部 `___XXX___` 形態的 `input string` 行
6. 對沒有 comment 的 input 自動補 comment（若對照表有提供）
7. `--dry-run` 模式：只印 diff，不改檔
8. 自檢：改名前後 brace 平衡、`input` 總數不變（除非對照表標記新增/刪除）

驗收：用 MT5 `TradeDashboard5.mq5` v1.51 跑 `--dry-run`，輸出應與 OpenClaw 手做的 FIX-TD8 結果一致（至少參數名集合相同）。

## 二、`scripts/check_input_standard.py`（CI 閘）

對每個 `.mq4/.mq5` 檢查，任一項不合格 → exit 1：

| # | 檢查 |
|---|---|
| 1 | 每個 `input` 都以 `Inp` 開頭 + PascalCase（無底線、無全大寫縮寫） |
| 2 | 每個 `input` 都有 comment |
| 3 | 無 `input string ___` 假分隔 |
| 4 | `input group` 存在且次序符合 `AGENTS.md` 第 3 節 |
| 5 | 風控類（名稱含 `Ddg`/`News`/`SymbolGuard`）預設值為 `false` 或 `0` |
| 6 | 版本號四處一致（`#property version` / description / `STARTED` banner） |

輸出格式：`檔案:行: 規則: 訊息`（grep 可用），exit code 供 CI 用。

## 三、`scripts/check_param_parity.py`（MT4 / MT5 對等閘）

輸入：一對 `.mq4` + `.mq5`（同一個 EA 的兩平台版本）
檢查：
1. 兩邊 input 名集合完全相等（缺一即 FAIL，列出差異）
2. 同名 input 的**類型**一致（`bool`/`int`/`double`/`string`）
3. 同名 input 的**預設值**一致
4. group 歸屬一致

驗收：故意把 MT5 側一個參數改名，腳本要 FAIL 並指出哪一個。
