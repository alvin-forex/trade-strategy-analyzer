## 二、目標架構

```
docs/index.html
├─【排名】→ signal_ranking.html（加密）
│   grain: per-signal（150 個 signal，跨 symbol 聚合）
│   欄位沿用：Signal / EA / CCY數 / DDE v5 / CB / Win% / Trades / PF / Profit / Max DD / WAL
│   工作：視覺全面重做，套 tsa_tokens.css + 方案C NAV，邏輯（評分/排序/紅卡）不動
│
├─【CCY】→ ccy_ranking.html（加密）
│   grain: signal 數據拆細 → 三層
│   ① 主表 貨幣對 × 方向（82 組合）
│   ② 鑽取 貨幣對 × 方向 × 馬汀層級 L1→L9+（598 組合）
│   ③ 匯總 單一貨幣 × 方向（38 組合）
│
└─ projection.html → 退役
```
