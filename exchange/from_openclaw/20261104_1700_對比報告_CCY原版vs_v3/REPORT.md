## 3. 根因（已定位，有證據）

1. **時間軸無錯位**：lag sweep −3…+3 bar，H4 最佳喺 lag +1（ρ 0.629 vs lag0 0.611）、H1 最佳 lag 0，**冇任何 lag 大幅跳升** → 唔係時區／shift 錯配。
2. **權重法根本不同（主因）**：v3 用 **ATR% 加權**（`W()` = ATR/price×100，再除 avgW），原版係**等權**（`sum[i]/cnt[i]`，每 pair 一票）。加權後再對 28 對取平均，令離散度被大幅攤平 → 正好解釋 0.44× 壓縮。強波動幣（JPY／CHF）被放大 → 正好對上 +10／+4 嘅 bias 方向。
3. **XAU 計法係另一個世代**：原版 XAU = XAUUSD 單一 RSI 直接映射；v3 XAU = XAUUSD ＋ 7 條黃金交叉（XAU/EUR、XAU/GBP…）＋半權重回饋其他幣。ρ≈0.6 屬設計差異，**唔應追成 bug**。
4. **v3 獨有功能**：ATR 加權、slope、panel 分級，原版全無。即兩個唔同世代指標，ρ=0.66 屬合理範圍，非實作錯誤。
5. **`PairTF` 寫死 H1**（`CurrencyPower_v3.mq5:53`）：掛 H4 圖上，pair RSI 仍用 H1 算。交叉測試：`v3_H4 × 原版_H4` = 0.665 高於 `v3_H4 × 原版_H1` = 0.334，但 `v3_H1 × 原版_H4` = 0.644 反而高於 `v3_H1 × 原版_H1` = 0.472 → **跨 TF 一致性本身有問題**。建議列為 v3 待修項（唔屬本項範圍）。
