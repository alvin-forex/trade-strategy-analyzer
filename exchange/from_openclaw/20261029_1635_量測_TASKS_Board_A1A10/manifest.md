# 三、要修嘅三項（都係細項，唔阻簽核流程但上線前要清）

## (1) 390px 有一處 3px 文字溢出 —— A1 其實唔算全綠

390 寬下 `.t`（任務名「報告來源簡寫（生成器 patch＋今日報告手術修）」）`scrollWidth 329 > clientWidth 326`，差 **3px**。

- 已設 `overflow-wrap: anywhere`，但長串「生成器 patch＋」+ 全角「＋」混合，Chrome 計算寬度時中英混排 break 位對不上。
- 影響：`documentElement` 層面仍算零橫向捲動（A1 九寬都過），但係一個 cell 內部溢出，截圖放大會見到字貼邊。
- 修法：`.t` 加 `word-break: break-word;` 或把「＋」前後加 `<wbr>`；最簡單係 `.c-task .t { overflow-wrap: break-word; word-break: break-all }`，字數少唔會影響 A5。
