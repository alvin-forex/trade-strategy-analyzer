1.2 Edge 驗證方法論

每個策略必須通過以下 5 層驗證先可以進入開發階段：

  1. 統計顯著性：最少 200 筆交易，勝率 95% 信賴區間唔包含 50%
  2. Walk-Forward Analysis (WFA)：
    • In-sample: 6 個月優化 → Out-of-sample: 2 個月測試
    • 滾動窗口重複 ≥ 5 次
    • Walk-Forward Efficiency (WFE) ≥ 50%
  3. Monte Carlo 模擬：1,000 次交易順序打亂，95% 分位嘅 Max DD ≤ 25%
  4. 噪音測試：加入 ±5% 價格噪音，策略仍盈利
  5. 隨機基準比較：策略必須跑贏 95% 嘅隨機信號策略
⚠️ 過擬合防範清單：
  • 參數數量 ≤ 5 個（越多越容易過擬合）
  • 唔好「cherry-pick」最佳參數組合
  • 用 Separation Ratio ≥ 2.0 判斷參數穩定性
  • 不同時間段、不同幣對嘅表現一致性

// Zone 識別系統
int IdentifyZone(double price, double atr, double ma) {
    double zone_size = atr * ZoneMultiplier;
    double upper = ma + zone_size;
    double lower = ma - zone_size;
    if (price > upper) return ZONE_BREAKOUT_UP;
    if (price < lower) return ZONE_BREAKOUT_DOWN;
    return ZONE_INSIDE;
}

// 趨勢過濾（D1 EMA + ADX）
bool TrendFilter(int symbol) {
    double ema_fast = iMA(symbol, PERIOD_D1, 20, 0, MODE_EMA, PRICE_CLOSE, 0);
    double ema_slow = iMA(symbol, PERIOD_D1, 50, 0, MODE_EMA, PRICE_CLOSE, 0);
    double adx = iADX(symbol, PERIOD_D1, 14, PRICE_CLOSE, MODE_MAIN, 0);
    return (MathAbs(ema_fast - ema_slow) > 0.001) && (adx > 25);
}

Strategy C：Smart Martin Recovery (SMR-EA)

高風險 · 需嚴格風控 基於全體數據嘅馬丁加碼管理策略

維度設計
策略類型受控馬丁加碼（Zone Recovery 變體）
核心原理方向錯誤時，唔係盲目加倍，而係喺 Zone 反轉點開對沖倉，利用價格波動回收虧損
加碼規則Level 0: 0.01 lot → Level 1: 0.02 → Level 2: 0.03 → Level 3: 0.05 → Level 4: 0.07
唔超過 Level 4（最大累積倉位 0.18 lot）
止損機制硬性 Max DD Stop：帳戶虧損 ≥ 15% 即刻全部平倉
時間止損：Level 4 持倉超過 48 小時則平倉
適用場景高波動品種（XAUUSD、GBPJPY）+ 明確區間震盪
禁用場景重大新聞前後（NFP、FOMC、CPI）| 強單邊趨勢中
⚠️ 馬丁策略風控紅線：
  • 初始倉位必須極細：$10,000 帳戶 → Level 0 = 0.01 lot
  • 每日虧損上限：帳戶 3%（到達即停 EA 當日）
  • 每週虧損上限：帳戶 6%（到達即停 EA 一週）
  • 最大同時馬丁序列：1 個（唔好同時跑多個馬丁 recovery）
  • 帳戶淨值 / 餘額比 < 0.85 時暫停開新倉

🛡️ 多層風控架構（強制執行）

Layer 1：交易級風控（每筆交易）

規則參數執行方式

Spread 過濾當前 spread > 入場阈值拒絕下單 + 記錄

Layer 2：倉位級風控（整體持倉）

規則參數
最大同時持倉數5 個（所有 EA 合計）
最大同方向曝光3 個（避免同方向堆疊）
幣對相關性控制相關係數 > 0.7 嘅幣對唔同時同方向
總曝險所有持倉風險總和 ≤ 6% 帳戶

Layer 3：帳戶級風控（日/週/月）

級別觸發條件動作
日止損當日虧損 ≥ 3%停止所有 EA，次日重啟
週止損當週虧損 ≥ 6%停止所有 EA，下週重啟 + 參數 review
月止損當月虧損 ≥ 10%停止所有 EA，人工 review + 參數重新優化
Max DD Stop歷史最大回撤 ≥ 20%永久停止 + 全面策略檢討

Layer 4：動態倉位管理（Kelly + ATR）

// Quarter-Kelly Position Sizing
double CalcKellyLotSize(double win_rate, double avg_win, double avg_loss, double equity) {
    double W = win_rate;                    // 勝率
    double R = avg_win / MathAbs(avg_loss); // 盈虧比
    double kelly = W - (1 - W) / R;         // Kelly %
    double safe_kelly = kelly * 0.25;       // Quarter Kelly
    
    // ATR 動態調整
    double atr = iATR(Symbol(), PERIOD_H1, 14, 0);
    double risk_amount = equity * safe_kelly;
    double sl_pips = atr * 2 * 10;          // 2x ATR stop loss
    double pip_value = MarketInfo(Symbol(), MODE_TICKVALUE);
    double lots = risk_amount / (sl_pips * pip_value);
    
    return NormalizeDouble(lots, 2);
}

模組化 MQL4 架構

// ===== EA 模組結構 =====
//
//  MainEA.mq4 (主入口)
//  ├── Config.mqh          (策略參數 + 常量)
//  ├── RiskManager.mqh      (風控引擎)
//  ├── SignalEngine.mqh     (信號生成)
//  ├── OrderManager.mqh     (訂單管理)
//  ├── TrailingStop.mqh     (移動止損)
//  ├── NewsFilter.mqh       (新聞過濾)
//  ├── SessionFilter.mqh    (交易時段)
//  ├── CorrelationFilter.mqh(相關性控制)
//  ├── Logger.mqh           (日誌系統)
//  └── Dashboard.mqh        (圖表顯示)
//
// 每個模組獨立測試 → 整合測試 → 實盤

//===== RiskManager.mqh 核心邏輯 =====
class CRiskManager {
private:
    double m_daily_pnl;
    double m_weekly_pnl;
    int    m_daily_trades;
    
public:
    bool CanTrade() {
        if (m_daily_pnl <= -DailyMaxLossPct * AccountEquity())   return false;
        if (m_daily_trades >= MaxDailyTrades)                     return false;
        if (CountOpenPositions() >= MaxTotalPositions)            return false;
        if (GetSpread() > MaxSpread)                              return false;
        if (IsHighImpactNews())                                   return false;
        return true;
    }
    
    double CalcLotSize(double sl_pips) {
        double risk_amt = AccountEquity() * RiskPerTradePct;
        double pip_val  = MarketInfo(Symbol(), MODE_TICKVALUE);
        double lots     = risk_amt / (sl_pips * pip_val);
        return NormalizeDouble(Min(lots, MaxLot), 2);
    }
};
