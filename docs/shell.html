呢個頁面做咩

TSA（Trade Strategy Analyzer）分析 AlgoForest 交易信號，產生馬丁/深度分析報告同排名頁。 全站有九百幾個 HTML 頁面，以往每頁各自載入自己嘅側邊欄，深度一改就全站有斷鏈風險。

Shell 模式改為「一個側邊欄 + iframe 內容區」：左邊導航只此一份，內容頁載入時唔再重複注入側邊欄， 所以行到邊一頁都唔會迷路。直接開舊網址（例如 volatility.html）照樣正常顯示， 搜索引擎同舊書籤唔受影響。

點用

  • 撳左邊任何一項 → 右邊載入該頁，網址會變成 shell.html#/頁面路徑，可以直接複製分享。
  • 瀏覽器上一頁／下一頁照常運作，因為每次切換都會記錄瀏覽歷史。
  • 底部按鈕切換深色／淺色模式，設定會記住，內容頁同側邊欄會同步變色。
  • 手機／窄視窗：左上角 ☰ 打開側邊欄，撳外面任何位置收返埋。

加密頁面

Signal 排名、CCY 排名同首頁屬 StatiCrypt 加密頁，揀入去會見到密碼輸入框， 解鎖後就可以喺同一個 shell 內瀏覽，側邊欄唔會消失。
