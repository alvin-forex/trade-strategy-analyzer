## 1. 為什麼 level / slope / cross 全部唔得（根因）

power diff(t) 對過去與未來回報嘅相關性（D1、12 pair、n=22,713）：

| 對比 | r | r² |
|---|---|---|
| 過去 3 日 | **−0.476** | **22.6%** |
| 過去 2 日 | −0.429 | 18.4% |
| 過去 1 日 | −0.345 | 11.9% |
| 未來 1 日 | +0.017 | 0.03% |
| 未來 3 日 | +0.025 | 0.06% |
| 未來 10 日 | +0.027 | 0.07% |

power 有 22% 由過去價格決定，對未來解釋力 0.07% — **本質係照後鏡**。任何由 power 導出嘅單一訊號（斜率、動量、Z-score、加速度）都逃唔出。必須把 power 當「條件濾網」而唔係「方向來源」，才有機會。

## 2. 唯一站得住嘅結構

### 定義

1. **找位**：H4 pivot(k=3) 產生嘅高／低點，之後重新被觸及時判定假突破：
   - 阻力：該 bar `high > level + 0.10×ATR` 但 `close < level` → fade 做空
   - 支持：該 bar `low < level − 0.10×ATR` 但 `close > level` → fade 做多
2. **過濾**：`sign(fast diff) == fade 方向` **且** `sign(slow diff) == fade 方向`
   - fast = `PowerHistory_H4_10.dat`（10 期）
   - slow = `PowerHistory_H4_120.dat`（120 期）
3. **出場**：下一 bar 開盤入場，TP = 2×ATR，SL = 1×ATR，最多持 8 bar

### 結果（TP=2ATR / SL=1ATR）

| 過濾條件 | n | 平均 R | t | 勝率 |
|---|---|---|---|---|
| 無過濾（全部假突破） | 9,287 | +0.029 | +2.15 | 39.7% |
| 快 diff 同 fade 方向 | 3,377 | +0.204 | +8.86 | 45.9% |
| 慢 diff 同 fade 方向 | 3,511 | +0.112 | +5.07 | 42.1% |
| **快＋慢都同 fade 方向** | **1,698** | **+0.272** | **+8.27** | **47.3%** |
| 快＋慢都「反」fade 方向 | 4,097 | −0.086 | −4.48 | 35.7% |

### 「數 bar」加強（老闆提出嘅做法）

按 pivot 之前被觸及次數分層（快慢同向）：

| 觸及次數 | n | 平均 R | t |
|---|---|---|---|

**觸及越多，平均 R 略升但 t 下降（樣本減少）。方向上正確，但唔算強力增量。**

## 4. 限制（照直講）

1. **只有 4 個 pair 有 8 年 H4 價格**。其餘 22 個 pair 嘅 `.hst` 只有 1.7 年（2025-02 起）。要全 pair 驗證必須補數據。
2. **H1/M30 只有幾個月**（Alpari H1 2026-06 起、M30 2026-08 起）。老闆講「配對唔同 TF」，目前只能用 H4 上嘅 fast/slow power 週期做跨尺度，**未能做真正嘅 H1×H4 或 H4×D1 配對**。
3. **2024 年為負**。需查是否與特定市場狀態（低波動／趨勢市）有關，未做。
4. **成本未精算**。ATR 以價格計，跨 pair 貨幣單位不同，需逐 pair pip value 換算。
5. 假突破判定用 pivot(k=3, lookback=200)，未做參數敏感度全掃。
