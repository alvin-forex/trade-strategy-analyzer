## 3. 馬丁偵測（LotTiers）— 原檔公式我讀到嘅口徑

| 項目 | 原檔做法 | 我會照做 |
|---|---|---|
| 基準 lot | 出現次數最多的實際 lot（COUNTIF 排序取最大頻次） | 相同 |
| 初步倍數 m0 | 由 lot 分佈推（B5 公式：以最大 lot 與基準 lot 關係計） | 相同，並在頁面顯示中間值 |
| 校準 lot | 出現 ≥2 次的最大 lot | 相同 |
| 校準層差 | 由 ln(校準 lot ÷ 基準 lot) 推層數 | 相同 |
| 偵測倍數 | `(校準 lot ÷ 基準 lot)^(1÷層差)`，四捨五入 | 相同 |
| 判定 | 有數據 → 有／無馬丁；並計「歸層比例」 | 相同 |
| 未歸類 | lot 不在層集合內的比例 | 相同，並列出未歸類 lot |

**驗收**：對同一份 CSV，網頁顯示的「基準 lot／偵測倍數／判定／歸層比例」要與 Excel `LotTiers` B1–B4 完全一致。
