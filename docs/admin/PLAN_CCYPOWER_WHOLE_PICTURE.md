# CCY Power × 回測體系 — 總體規劃（Whole Picture）

> 版本 v1｜2026-11-26｜撰寫：AUTOCLAW（AC lane）｜需老闆批核後才逐項執行
> 觸發事件：實測發現「Power Diff 對下一根方向無預測力（H1 48.7%／H4 50.9%）」，並揭出一個會令任何回測虛高的對齊陷阱。

---

## 0. 一頁總結

- **已知**：面板值＝整數÷對數（分母 8／7／4）；九幣整數分總和長期約 263；原作三道統計指紋已量到；已否證十個公式方向。
- **今次新發現（重要）**：Power 的變化（差分）**不能**預測下一根方向。表面 80% 命中完全是「時間對齊錯位」造成的自我循環。
- **含意**：過去所有「Power 有幾成命中」的講法都要重新審核；訊號必須重新建立在**無前視**的驗證框架上。
- **做法**：先把驗證框架做硬（防假命中），再逐層重建訊號，最後產品化。**先後次序不可倒轉**。

## 1. 三條主線（整個體系的骨架）

| 代號 | 主線 | 目標一句話 | 完成標誌 |
|---|---|---|---|
| **L1** | 驗證基建 | 任何訊號都必須在「無前視、可重跑、有樣本外」的框架下量度 | 一個框架＋一份審核清單，能一次過否決假命中 |
| **L2** | 訊號工程 | 找出真正有預測力的條件組合（Power × 價格結構 × 時框） | 樣本外穩定、可解釋、可回測的訊號定義 |
| **L3** | 產品化 | 把有效訊號變成可跑的 EA／報告／日常監控 | 一鍵出 29 品種原生回測報告＋每週復盤 |

三條線有嚴格依賴：**L1 → L2 → L3**。L1 未完成，不做 L2；L2 未達標，不做 L3。

### P0 — 立規矩（1–2 日）

## 4. 執行協議（逐項推進，不跳步）

1. **我一項一項提**：每項寫「目的／輸入／方法／交付／驗收／風險／工時」。
2. **你批一項，我做一項**：未批不動手；一項未完成不開第二項。
3. **做完即報**：結果寫入 GitHub 卡（唯一真相源），並在對話用 5 點內講清楚。
4. **每項都有止損**：若兩次嘗試仍未達標，即停手報告「此路不通」，不硬撐。
5. **每項都要能重跑**：附腳本與原始輸出，否則視為未完成。

## 6. 風險與止損規則（寫死）

| 風險 | 症狀 | 對策 |
|---|---|---|
| 對齊錯位 | 命中率突然 70–90% | 強制報對齊；重跑嚴格下一根 |
| 過擬合 | 樣本內好、樣本外崩 | 限制組合數；樣本外只跑一次；記錄嘗試次數 |
| 多重比較 | 試 100 個總有幾個「好」 | Bonferroni／deflated Sharpe |
| 樣本太短 | 720 小時＝30 日 | 只用於探索；驗證用 2015–2026 |
| 倖存者偏差 | 只留現存 28 對 | 商品池事前寫死 |
| 數據源不一致 | MT4 與 MT5 差第 5 位 | 標明來源；容差寫入報告 |

- 驗收：能自動把今日「80%」判定為假；把我過去所有報告過的命中率逐項重標。
- 風險：會否決我們自己過去的部分結論——這是預期效果，不是壞事。
