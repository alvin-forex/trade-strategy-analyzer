# 提交格式（外部核對者）

多謝你參與。請按以下格式提交，我方的自動核實程式會直接讀取。

## 一、提交位置

在 GitHub 這個 repo 開 PR，新增資料夾：

```
docs/admin/ccy_power/submissions/<你的名稱>_<YYYYMMDD>/
├── formula.md        必要：公式說明（幾句話 + 偽碼）
├── verify.py         必要：可重跑腳本（讀 ../sample 的兩份 CSV）
├── output.txt        必要：腳本原始輸出（不准手寫、不准摘要）
└── notes.md          選填：失敗記錄、試過的維度、反例樣本
```

我方只會**閱讀** `verify.py`，**不會執行外來程式碼**。所以 `output.txt` 必須是完整原始輸出，
包含每個指標的數值；我方會用自己的程式重算一次作核對。

## 二、必要指標（`output.txt` 必須包含）

| 指標 | 說明 | 門檻 |
|---|---|---|
| `exact_hit_rate` | `|pred − 面板值| < 1e-4` 的比例（CHF，全部可用時點） | ≥ 0.99 |
| `mae_integer` | 以整數單位計的平均絕對誤差 | < 0.05 |
| `sd_U_CHF` | CHF 的 U＝v×7 序列標準差 | 9.3 – 13.6 |
| `acf1_U_CHF` | 上述序列一階自相關 | 0.72 – 0.86 |
| `mean_U_CHF` | 上述序列平均 | 28.6 – 37.1 |
| `sum8_U` | 八個非黃金貨幣 U 的總和平均 | 260 ± 15 |
| `xcorr_CHF_EUR` | CHF 與 EUR 的 U 序列相關 | −0.20 – 0.00 |
| `U_max` | U 的最大可能值 | = 9 × N |

## 三、樣本範圍（重要）

- 面板值請用 `docs/admin/ccy_power/sample/panel_values.csv`（已篩走「非真面板」行）。
- 價格請用 `docs/admin/ccy_power/sample/prices_h1.csv`。
- **不准自行生成、插值、或補齊缺失 bar**；缺樣本請在 `notes.md` 說明並剔除該時點。

## 四、會被打回的情況

1. 只交結論、沒有 `output.txt` 原始輸出。
2. 自由參數 ≥ 5 個而沒有說明參數怎樣定（視為擬合）。
3. 用相關係數當主要證據（corr 0.8 以下不算；corr 高但 acf1 > 0.86 亦當假）。
4. 改動樣本數據、或只用部分時點而沒有說明（挑樣本 = 無效）。
5. 指標名稱或格式與上表不符（我的程式會讀不到，直接當未提交）。

## 五、已否證方向（不要重做）

詳見 `docs/admin/ccy_power/CROSSCHECK_BRIEF.md` §4，共 10 項，附量法與數字。
如你認為任何一項判錯，請在 `notes.md` 附反例：時點、期望值、你的計算值。
