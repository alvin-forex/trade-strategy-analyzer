# 給外部 AI 的核對指令（可直接複製）

以下整段複製，貼給任何有能力執行程式碼的 AI（Claude／GPT／Gemini／本地模型都可以）。

---

```
你係獨立核對員。任務：反推一支外匯指標的計分公式，並用我提供的樣本證明。

【背景】
一支已停售的 MT4 指標會在面板顯示 9 個貨幣的強弱分數（0 至 9 左右的小數）。原作者已故，無源碼，
只有觀測值。我們已試過十個方向都失敗，需要你獨立再做一次，或者指出我們的錯處。

【讀這三份，全部可公開下載】
1. 任務書（必讀，含已確立事實、已否證清單、陷阱、交付格式）：
   https://raw.githubusercontent.com/alvin-forex/trade-strategy-analyzer/main/docs/admin/ccy_power/CROSSCHECK_BRIEF.md
2. 樣本：真面板數值（208 個時點 × 9 貨幣）
   https://raw.githubusercontent.com/alvin-forex/trade-strategy-analyzer/main/docs/admin/ccy_power/sample/panel_values.csv
3. 樣本：對應的 28 條貨幣對 H1 價格
   https://raw.githubusercontent.com/alvin-forex/trade-strategy-analyzer/main/docs/admin/ccy_power/sample/prices_h1.csv

【已確立，可以直接用】
- 面板值 = 整數 ÷ 對數。分母：EUR/USD/AUD = 8，GBP/JPY/CHF/CAD/NZD = 7，XAU = 4。
  即每一條貨幣對先有一個 0 至 9 的整數分，再對該貨幣的所有對取平均。
- 八個非黃金貨幣的整數分總和長期穩定在 263 左右。
- 三道統計指紋（原作實測）：波動 9.3–13.6、一階自相關 0.72–0.86、總和 260±15。

【你要交的】
1. 一個公式（幾句話講清楚 + 偽碼）：每條貨幣對在每個時點的值是怎樣算出來的。
2. 一段可重跑的腳本（讀上面兩個 CSV）。
3. 驗證表：完全命中率、平均誤差、三項指紋。
4. 如果你也失敗，列出你試過的方向與最佳數字（同樣有價值）。

【硬性要求】
- 判定標準只有一個：完全命中率 ≥ 99%（現時最好 4.9%）。
- 相關係數 0.8 以下不算答案；相關係數高但自相關超過 0.86 亦算假（那是「太滑」造成的假象）。
- 面板只有 4 位小數，判斷「是否整數」的容差用 1e-3，不要用 1e-6。
- 時間對齊用 bar 開始時間，已驗證偏移 0 為最佳。
- 有 5 個以上自由參數的候選，要一併解釋參數怎樣定，否則當擬合。
- 唔准改動或重新生成樣本數據；只可以用我提供的兩份 CSV。

【輸出語言】繁體中文。先講結論，再附證據。
```

---

使用提示：
- 若對方 AI 不能上網，請先把三個檔案下載，再整段貼（任務書＋兩份 CSV 內容）給它。
- 若對方回覆「已完成」，要求它貼出腳本與原始輸出；沒有腳本與原始輸出的結論一律不接受。
