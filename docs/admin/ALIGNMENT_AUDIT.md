## 三、工具自檢（證明檢查器真能抓假）

對同一組 Power Diff 預測跑 `align_guard.py`：

```
strict   42.7% (114/267)
overlap  84.6% (226/267)
診斷 最佳偏移：-1 根 → 84.6%
判定：重疊對齊比嚴格高 41.9 個百分點 → 作廢；最佳偏移在 -1 根 → 不准採用；嚴格模式 42.7% 接近隨機 → 無預測力
可採用：否
```

即：同一個策略，只靠改對齊就可以由「四成二」變成「八成五」。這就是本檢查器存在的理由。

## 四、對外表述紀律（即時生效）

1. 任何命中率必須同時寫：樣本期、樣本數、對齊方式、是否含形成中 bar。
2. 未過 `align_guard.py` 的數字，一律標「未證實」，不得寫入報告首段。
3. 相關度不可以單獨作為結論；必須附命中率或分層單調性。
4. 若同一策略在 strict 與 overlap 差異 >10 個百分點，報告必須同時列出兩個數字並解釋差異。
