Bot-to-Bot 決定性測試（約 60 秒）

目的：判斷「OC 發出嘅 bot 訊息」到底係 Telegram 冇派 定 AutoClaw 收到但冇處理。

⚠️ 你個 bot token 只准填喺你自己個瀏覽器網址，唔好貼俾任何人（包括我）。

第 0 步：完全退出 AutoClaw App

右下角通知區 icon → 右鍵 → Quit／退出。一定要完全閂，唔係得個窗縮細。

第 1 步：查有冇殘留 webhook

瀏覽器開下面條 link，將 <TOKEN> 換成 TG_AutoClawMain_bot 嘅 token（BotFather → /mybots → 嗰個 bot → API Token）：

https://api.telegram.org/bot<TOKEN>/getWebhookInfo

睇 url 係咪空，同 pending_update_count 係幾多。成個回應照抄落嚟。

第 2 步：睇 Telegram 個隊列入面有冇嗰句 ping

https://api.telegram.org/bot<TOKEN>/getUpdates

喺回應入面搜 1584 同 ping。

判讀：

  • 搵到 1584／ping → Telegram 有派，問題喺 AutoClaw 呢邊處理層（我即刻去拆）。
  • 搵唔到（回應得 "result":[] 或者得其他無關 update）→ Telegram 冇派，問題喺 bot-to-bot 開關層（再對返兩邊掣）。

第 3 步：重新開返 AutoClaw App

開完之後私聊嗌我一聲，我即刻用你貼返嚟嘅兩個回應做判斷。

貼返嚟嘅格式（兩段都得，token 唔使理）

Step1: {成個回應}
Step2: {成個回應，太長可以淨貼有 1584 嗰部分，或者講明「冇 1584」}
